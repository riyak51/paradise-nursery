# Paradise Nursery Shopping Application

## Project Description

Paradise Nursery is an online plant shopping application built using React and Redux Toolkit. It allows users to explore houseplants, view their prices, add plants to a shopping cart, and manage their purchases.

## Features

* Interactive landing page with a Get Started button.
* About Us page describing the company.
* Plant listings organized into categories.
* Add-to-Cart functionality.
* Shopping cart with quantity management.
* Automatic price calculations.
* Delete items from the cart.
* Responsive navigation bar.
* Checkout message indicating that the feature is coming soon.

## Technologies Used

* React
* JavaScript
* CSS
* Redux Toolkit
* React Redux
* React Router
